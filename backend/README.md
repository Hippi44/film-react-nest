# Бэкенд

Установите PostgreSQL и создайте базу данных `films` и пользователя для неё. Затем установите зависимости и запустите сервер:

```text
npm ci
Copy-Item .env.example .env
npm run start:dev
```

Настройки подключения находятся в `.env`. TypeORM создаёт таблицы при запуске. Постеры доступны по пути `/content/afisha/`.
